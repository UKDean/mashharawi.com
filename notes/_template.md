HOW TO PUBLISH A NOTE

1. Copy this file to notes/YYYY-MM-DD-a-short-slug.md
   The slug becomes the URL: mashharawi.com/writing/a-short-slug/
   Use lowercase letters, numbers and hyphens only.
2. Fill in title, date, summary, and the body.
3. Set lang to ar for an Arabic note; it renders right to left automatically.
4. Commit. The GitHub Action rebuilds the page, the index, feed.xml and sitemap.xml.
5. Zapier sees the new item in feed.xml and posts it to LinkedIn.

Files starting with an underscore are ignored, so this one never publishes.
