Construction Dictionary: guide

How to find a construction term in any of the three languages, read its definition and copy the equivalents into your documents.

What the tool does

The dictionary holds 189 terms for reinforcing steel, concrete, structural and civil engineering, site work, procurement, QA/QC, logistics, drawings and safety. Each term is given in English, Arabic and Chinese, with a short working definition in each language, synonyms and regional names, and links to related terms.

When to use it

  • To find the English or Chinese name of a term you know in Arabic, or the other way round.
  • To check what a term on a drawing, submittal or delivery note means.
  • To write a message or document for a team that works in another language.

Step by step

1. Search in any language

Type in the search box in English, Arabic or Chinese. Results appear while you type; there is no button to press.

  • Part of a word is enough: “lap” finds Lap splice, “كان” finds الكانة, “坍落” finds 混凝土坍落度.
  • Synonyms and site names are searched too: “كمرة” finds Beam, “螺纹钢” finds Deformed bar, “MTC” finds Mill test certificate.
  • English is not case sensitive. Arabic is normalised: أ إ آ count as ا, ة as ه, ى as ي, and diacritics are ignored, so “كانه” finds الكانة. A leading “ال” is optional.
  • Several words must all match: “stirrup beam” shows the entries that contain both.
  • Definitions are searched as well, so a word that only appears in a definition still finds the term, ranked below terms whose name matches.
  • Matches are highlighted. Press × or Esc to clear the search.

2. Narrow by category

The ten categories are Reinforcing Steel, Concrete, Structural Engineering, Civil Engineering, Construction Site, Procurement, Quality Control (QA/QC), Logistics, Drawings and Specifications, and Health and Safety. Choose one to see only its terms; the number on each button shows how many terms match the current search. A search and a category work together. Reset filters clears both.

3. Read the entry

  • The three terms are listed one per line: EN, AR, ZH.
  • The definition in the page language is shown under them. Open Definitions, synonyms and notes for the definition in the other two languages, all synonyms, an example and notes where there are any. If a search matched only inside this panel, it opens by itself.
  • Related terms are links: select one to jump to it.
  • Abbreviations such as MTC, NCR or BBS are shown next to the category.

What “To be reviewed” means

A translation marked To be reviewed has regional variants or no settled equivalent, for example the Arabic for development length or the Chinese for request for information. It is the best available term, not a confirmed one: check it against the project documents or with the other party before using it.

4. Copy a translation

Each language line has a Copy button that copies that term only. Copy all three copies the three terms on three lines, ready to paste into an email or a table. A short message confirms the copy. If the browser blocks the clipboard, select the text and copy it yourself.

Worked example

From an Arabic site word to the English and Chinese terms

A foreman writes that the “كانات” in a beam are too far apart. Type كانات: one result, Stirrup · الكانة · 箍筋, because “كانات” is listed as a synonym. Its definition explains that stirrups enclose the main bars and resist shear.

Copy all three places this on the clipboard:

LineCopied text
1EN: Stirrup
2AR: الكانة
3ZH: 箍筋

Typing جسر instead finds Beam first; the note on that entry says that Saudi sites say جسر and Egyptian usage كمرة, and both words find it.

Reading the results

  • The count shows how many terms match, out of all terms.
  • Order: while searching, entries whose name matches come first, then synonyms and abbreviations, then definitions. Without a search, entries are grouped by category.
  • No result: try a shorter part of the word, the same word in another language, or All categories.

Common mistakes

  • Treating a working definition as the text of a standard: the specification and the code it cites govern.
  • Using a term marked “To be reviewed” in a contract document without checking it.
  • Searching a whole phrase in one language and expecting a different wording to match: search a key word instead.
  • Assuming one Arabic site word means the same everywhere: check the synonyms and notes.

Limitations

  • The dictionary is a terminology reference, not a design code or a translation service. Definitions are short and general.
  • It does not translate sentences, and it covers only the 189 terms in it.
  • Regional usage differs, especially in site Arabic; the most common names are listed as synonyms, not every variant.
  • Search runs on the list loaded with the page; it does not look anything up on the internet.
  • Nothing you type is sent or stored, so there is no search history.
