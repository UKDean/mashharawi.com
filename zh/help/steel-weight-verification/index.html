钢筋重量核对：使用指南

如何将钢筋试样的实测重量与理论重量比较，以及如何恰当地解读偏差。

工具用途

它根据试样的直径、长度和根数计算理论（公称）重量，并与试样实际重量比较：差值（公斤）和偏差（%）。它不判定钢材是否合格。

使用时机

  • 工地或仓库的到货检验。
  • 讨论发票前，将到货与理论重量对比。
  • 比较同一批次的多个试样。

操作步骤

1. 测量试样

  1. 切取一段平直钢筋，两端切平。
  2. 用卷尺或钢尺测量长度（尽量精确到毫米）。
  3. 用经过校准的秤称重；小试样请使用分度值细的秤。
  4. 也可以多根一起称重，记下根数即可。

2. 输入数值

  • 直径：点选规格（10–32 毫米）或输入其他值；其他规格标为非标准。
  • 牌号：仅供记录。Grade 60 与 Grade 80 的理论重量相同。
  • 试样长度：输入数字并选择毫米或米。工具保留您的单位，绝不猜测；1000 毫米与 1 米相同。接受不超过 12 米的任何正长度。
  • 称重根数和实测总重量（公斤），小数用小数点。
  • 编号和备注可选。

3. 输入您的范围（可选）

如果规范或合同规定了重量范围，请输入下限（零或负数，例如 −4）和上限（零或正数）。每个试样会显示在范围内或超出范围。这只是与您的数值比较。工具没有内置限值，也不作合格判定。

4. 添加试样

输入时即显示结果。点击添加试样保存到本次核对的表格中，然后输入下一个。

计算实例

单个试样

16 毫米，三根 1.000 米，实测 4.600 公斤。

  1. 每米重量 = 0.006165 × 16² = 1.57824 公斤/米。
  2. 理论重量 = 1.57824 × 1.000 × 3 = 4.73472 公斤。
  3. 差值 = 4.600 − 4.73472 = −0.13472 公斤。
  4. 偏差 = −0.13472 ÷ 4.73472 × 100 = −2.85%：试样比理论轻。

结果解读

  • 偏差符号。正值：比理论重；负值：比理论轻。
  • 单个试样偏差属于一个试样。合并偏差把同一直径的所有试样视为一次合并称重，旁边显示最低和最高试样，不掩盖单个结果；它不是百分比的平均值。
  • 全部试样的总质量只以公斤给出，不同直径绝不合并为一个百分比。
  • 输入检查。差值超过 25% 时显示中性提示，请您重新检查单位、根数和直径；这不是验收限值。
  • 只有在您输入范围时，才会显示在您输入的范围内 / 超出范围。

为什么偏差本身不能证明不合格

验收取决于适用标准和合同：试样数量、取样方法、试样长度、测量和称重精度以及适用的限值。用卷尺和工地秤称一次无法下结论。结果是理论比较，不是质保书（MTC），不是实验室试验，也不是证书。请用它来决定是否索取质保书或进行正式试验。

常见错误

  • 选择了“米”却输入毫米（或相反）：“输入检查”通常会提示。
  • 称了多根却把根数输入为 1。
  • 端部弯曲或不平，使测得的长度偏长或偏短。
  • 小试样使用分度值过粗的秤。
  • 把偏差当作合格或不合格。

局限

  • 仅为理论重量，按 0.006165 × d² 计算。
  • 没有内置允许偏差或标准。
  • 本次核对不会保存；请下载 CSV 或打印。
  • 精度取决于您的测量和秤。
